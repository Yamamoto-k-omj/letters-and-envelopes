# my_project

## 手紙と封筒

手紙と封筒をランダムに組み合わせる、講義用のシンプルな実験画面です。

`index.html` をブラウザーで開いて利用できます。外部ライブラリやインストールは不要です。ローカルサーバーを利用する場合は、このディレクトリで実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8000` を開きます。

- 手紙と封筒の数を2〜100組から選び、「組み合わせる」で実行します。
- 同じ番号の組を青く表示し、正解数と正解率を表示します。
- 「リセット」で選択中の組数の表示と記録を初期化します。組数を変更すると、その組数での記録に切り替わります。
- 20組以上かつ5組以上一致した場合にのみ、特別なエフェクトと、その一致数以上になる確率のメッセージを表示します。動きを減らす設定では、光の強調とメッセージだけを表示します。
- 試行を重ねたときの、全部不一致だった割合と一致数の平均をグラフで表示します。割合のグラフには比較用の1/eの参照線を表示します。平均の収束先は明示せず、実験から観察できるようにしています。
- 「1,000回実行」で記録を増やせます。封筒には最後の結果を表示し、その結果が条件を満たす場合に演出とメッセージを表示します。
- 表示する確率は完全順列から計算し、「指定した一致数以上」の場合の確率を合計します。非常に小さな確率は指数表記で表示します。
- Fisher–Yates 法で等確率に並べます。Web Crypto が使える場合は棄却法による整数乱数を利用します。
